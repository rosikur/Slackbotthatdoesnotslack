# Slackbotthatdoesnotslack
This is A slackbot that runs 24/7 on the Hackclub Slack via its nest server
## Features
-Ping (Pong)

-help (lists some commands)

-catfact(catfact)

-joke(joke)

## Usuage

To use those commands you type 

/slackbot-that-doesnt-slack-XXXX

replace XXXX with the commands above without the parentheses


Have fun with the jokes once in a blue moon they are actually funny
